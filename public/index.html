About this project

This site is served from EC2 instances behind an Application Load Balancer, auto-scaled based on demand, with data stored in Amazon RDS and static assets in S3.

What it demonstrates

High availability

Multi-AZ EC2 instances behind an ALB.

Auto scaling

Scales from 1 to 3 instances based on CPU load.

Managed database

Contact form data persisted in RDS PostgreSQL.
